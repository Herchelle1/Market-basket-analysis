Market Basket Analysis

A full-stack application that analyses transaction data to discover products frequently purchased together. It uses the Apriori algorithm to generate association rules and presents the results through a React-based interface.

PythonFlask REST APIApriori ReactPandas

Overview

Market Basket Analysis is a data-mining technique used to identify relationships between products in transactional data. This project applies association-rule mining to find product combinations and make the resulting patterns easier to explore through a web application.

The backend exposes a Flask REST API that performs the analysis using the Apriori algorithm. The React frontend consumes the API and displays the generated association rules in a structured table.

Key Features

Association Rule Mining

Uses the Apriori algorithm to identify frequent itemsets and product associations.

Configurable Thresholds

Runs the analysis with a minimum support threshold of 0.4 and confidence threshold of 0.6.

REST API Backend

Uses Flask to expose the analysis results to the frontend.

React Interface

Fetches association rules from the API and presents them in a readable table.

How It Works

  1. Transaction data: The analysis takes transaction data as its input.
  2. Frequent itemsets: Apriori identifies item combinations that meet the minimum support threshold.
  3. Association rules: Rules are generated and filtered using the confidence threshold.
  4. Rule evaluation: Support, confidence and lift are used to understand the strength and usefulness of each association.
  5. Frontend display: The React application retrieves the results from the Flask API and displays them in a table.

Understanding the Metrics

Support

Measures how frequently an item or item combination appears across all transactions.

Confidence

Measures how often the consequent appears in transactions that contain the antecedent.

Lift

Measures how much more often the antecedent and consequent occur together than would be expected if they were independent.

Technology Stack

  • Python: Backend programming and analysis logic.
  • Flask: REST API development.
  • Apriori: Frequent itemset mining and association-rule generation.
  • React: Frontend interface.
  • Pandas: Transaction data handling and analysis.
